# Java SPMF 2.64b

`python3 scripts/prepare_spmf.py --java java` tải JAR chính thức và đối chiếu
SHA-256. Cần Java ≥21. JAR được lưu local ở `tools/spmf.jar`.
SPMF chỉ xuất tập tham chiếu để kiểm kết quả của hai backend Julia.
